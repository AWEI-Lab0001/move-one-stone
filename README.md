# Move One Stone · 石头记

> 一天总会被填满，先放进真正重要的那一块。

石头记是一款手机优先的每日推进工具。它不记录所有忙碌，而是帮助用户选出真正重要的事情、拆成能够动手的小石头，并留下生活真正向前的部分。

## 当前功能

- 每日大石头、完成标准与加权进度
- 小石头拆分、1–5 重量、当前启动动作
- 完成动画、石头值、可选评价和成果图片
- 今日自由小石头
- 完成 7 个大石头后永久解锁第二块大石头
- 累计 5 天完成两块大石头后永久解锁第三块大石头
- 按日期查看历史记录
- JSON 数据导出、合并导入和覆盖导入
- 浏览器本地保存与可安装 PWA
- 透明水罐完成动画：重要的石头放进去，水被挤出来

## 数据说明

数据默认只保存在当前浏览器的 `localStorage` 中，不会自动同步到其他设备。成果图片会经过压缩后写入本地备份。建议定期从“数据”页面导出 JSON 文件。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开终端中显示的本地网址即可使用。

## 构建

```bash
npm run build
```
